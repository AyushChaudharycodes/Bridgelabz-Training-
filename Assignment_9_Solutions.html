Q6. Responsive CSS Cheat Sheet

Key concepts in responsive CSS, arranged in a Grid and stacked below 700px.

Filters

Apply visual effects to images.

filter: grayscale(1);

Media Queries

Apply styles at selected viewport widths.

@media (max-width:700px) { ... }

Responsive Design

Make content adapt to different screen sizes.

width: 100%; max-width: 900px;

Typography

Scale text fluidly with viewport size.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Create adaptable columns and rows.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Flexbox

Align items in a row or column.

display: flex; gap: 1rem;

Q9. Responsive Design Principles Summary

Three principle boxes include short definitions and CSS examples. Hover to see a gradient and text-color change.

Fluid Layouts

Use flexible widths that adjust to the viewport.

width: 100%; max-width: 1100px;

Flexible Media

Prevent images and media from overflowing their containers.

img { max-width: 100%; height: auto; }

Breakpoints

Change the layout when the viewport reaches a chosen size.

@media (max-width: 600px) { ... }
